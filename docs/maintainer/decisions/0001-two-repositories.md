# ADR-0001：软件与插件使用两个独立仓库

状态：Accepted  
适用范围：ToolBox 工作区

## 决策

`软件/` 维护 ToolBox 平台，`插件/` 维护官方及朋友插件。两者保留独立 Git 历史、分支、标签、提交和发布流程。工作区根目录不创建第三个父级 Git 仓库。

## 原因

- 插件开发不应修改平台源码。
- 软件和插件可以独立发布、回滚和审查。
- 朋友提交插件时只需要遵守 SDK 和 Manifest 契约。
- 工作区只负责本地组织，不成为新的发布单元。

## 结果

软件仓库通过发布的 `ToolBox.PluginSdk` 与插件协作。需要同时变更平台和插件时，使用兼容版本和明确的跨仓库任务，分别提交。
