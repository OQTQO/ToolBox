# ToolBox Host UI 设计基线

> 当前状态：原生 WPF Host 是唯一实现和验收基线；历史 HTML 文件仅作设计追溯，不再参与实现或验收。
>
> 适用范围：ToolBox WPF Host 的通用界面，不包含任何具体插件页面。

## 产品边界

ToolBox 是 Windows 上的通用插件管理工具。Host 负责安装、发现、导航、生命周期、通用状态、诊断和插件协议数据呈现；具体工具能力由独立插件提供。

- Host 不为任何 Plugin ID、插件类型或业务字段添加专属页面或样式分支。
- 插件只提供名称、发布者、状态、版本、运行模式、操作、输入和日志等协议数据。
- 新插件复用同一套导航、目录、详情和状态区块。
- 本基线只约束桌面软件，不把网页布局、浏览器行为或 HTML 模拟状态带入 WPF。

## 视觉系统

当前采用明亮的酸性彩场工具界面，目标是高可读、低装饰、紧凑操作，而不是营销 Dashboard：

- 画布：浅灰绿；表面：暖白；强调：酸性绿；文字：深墨色。
- 形状：窗口外框使用 Windows 原生窗口样式；大卡片 12–18px，控件 9px，状态标签 5–6px；不使用胶囊按钮、椭圆环或大面积装饰色块。
- 层级：通过边框、填充、间距和遮罩表达，不使用详情抽屉的大范围阴影或模糊。
- 酸性绿只用于真实操作、选中态和健康/运行状态；状态必须同时有文字，不依赖颜色单独传达。
- 品牌图标使用酸性绿底、深墨色工具箱几何标记；应用和托盘标识保持同源，不使用旧蓝色渐变或单字母占位。
- 字体优先使用 `Segoe UI Variable Text`、`Segoe UI Variable Display` 和 `Microsoft YaHei UI`；窗口外框和标题栏交给 Windows 原生非客户区绘制。
- 窗口外框、系统圆角、阴影和缩放命中由 Windows 原生非客户区负责；WPF 不再绘制透明根级外框或重复裁切，避免自绘描边与系统圆角错位。

## 窗口与导航

- 标题栏使用 Windows 原生标题栏、窗口控制和缩放命中；不再绘制自定义标题栏按钮或透明圆角外框。
- `TitleBarCenterText` 继续作为可编辑的系统窗口标题文案使用，默认本地化文案为“桌面工具管理”；空值回退默认值，单行最多 32 个字符。标题位置和系统按钮外观服从 Windows。
- 左侧导航固定为概览、插件、活动、设置；侧栏底部不重复放搜索提示。
- `Ctrl+K` 保留为隐式快捷键：切到插件页、聚焦搜索框并选中现有输入。
- “安装本地插件”仅在插件页内容区显示，位于搜索/筛选工具栏下方；标题栏和其他页面不出现入口。

## 页面与布局

- 内容在固定窗口内完成，长内容只在页面内部滚动；页面切换不做平移，最多保留短时透明度过渡。
- 概览只显示安装数量、运行数量、需要处理项、已安装工具、系统状态和最近活动；稀疏数据不使用大面积空占位。
- 插件工具栏由单层搜索框和筛选区组成。搜索框与插件卡片列表左边缘对齐，占据剩余宽度；筛选按钮与搜索框保持约 8–12px 间距。占位文案叠加在输入框内部，不额外绘制搜索边框。
- 排序按钮显示当前排序方式；筛选使用 canonical 值 `all`、`running`、`disabled`、`attention`。
- 插件目录使用 `ResponsiveCardPanel` 响应式两列网格：1–4 个插件保持 2×2 展示，不显示分页；5 个以上只增加页面内部滚动。空列表、单列、两列、异常尺寸和不完整末行必须安全。
- 插件卡片统一使用信息完整的重点结构，所有卡片高度、元数据和操作区域一致；不提供卡片尺寸切换。卡片“更多”菜单只包含“卸载”，不在菜单中提供隐藏入口。
- 详情使用右侧抽屉，打开后焦点进入关闭按钮，关闭后尽量恢复触发控件；遮罩可关闭。

## 设置与兼容性

“设置 > 外观”保留以下真实有效的界面选项：

- 自定义窗口标题文案、概览标题和系统状态标题；
- 减少动效、背景亮度、圆角和默认插件卡片尺寸；
- 插件行为、窗口关闭行为和语言选择。

标题、亮度和圆角输入在停止操作约 225ms 后提交，失焦、重置和窗口关闭时立即提交。`HostSettingsService` 使用锁保护状态、唯一临时文件和原子替换，只有实际变化才保存和触发 `Changed`。设置页不再显示默认卡片尺寸选择，卡片尺寸旧字段仅作兼容数据保留。

旧 JSON 字段继续读取：`Theme`、`DynamicGlow`、`Transparency`、`CornerRadius`、`PluginCardSizes` 以及原有概览文案字段。旧主题统一映射到当前酸性彩场；`DynamicGlow`、透明度等无当前视觉控件的字段只为兼容保留；圆角自动限制到 12–20px，背景亮度限制到 75–125。

## 清晰度与交互质量

- 使用 `ApplicationHighDpiMode=PerMonitorV2`；窗口外框由 Windows 原生非客户区按当前 DPI 绘制，普通窗口和最大化不再叠加 WPF 圆角。
- WPF 内容区保持布局取整和设备像素对齐；不使用透明窗口、`WindowChrome` 或自绘外框参与边框绘制。
- 布局开启取整和设备像素对齐；避免半像素边框、页面平移和持续模糊。
- 页面与详情滚轮每个标准刻度约 72px，约 180ms 缓动并合并连续事件；减少动效时直滚。嵌套 `ScrollViewer` 有可滚动空间时优先消费，到边界才交给外层；Home、End、PageUp、PageDown 保持原生行为。
- 安装、卸载、启停、插件输入、插件 UI 操作和目录打开必须经过可捕获的 Task 入口，并防止重复点击；异常进入 Host 错误状态和结构化日志。
- 所有按钮、输入框和开关键盘可达，具有明确名称、可见焦点和禁用态；正文、辅助文字、边框和状态颜色在浅色背景下保持可读。

## 当前实现与边界

`MainWindow.xaml` / `MainWindow.xaml.cs` 提供原生窗口标题栏下的导航、概览、插件目录、活动、设置和详情抽屉；`App.xaml` / `ThemeService.cs` 提供主题令牌；`HostSettingsService` / ViewModel 保持插件行为链路；`SmoothScrollController` 与纯计算层负责页面和详情滚动。

本轮只整改 WPF Host。历史 HTML 文件保留作资料但不再修改；新增的未跟踪 HTML 预览目录已删除。原生窗口边框的具体颜色、圆角和阴影会随 Windows 版本、主题和系统设置变化；客户区清晰度与真实插件操作仍以可见桌面人工验收为准。
