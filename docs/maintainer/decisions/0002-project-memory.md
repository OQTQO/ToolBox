# ADR-0002：项目状态以仓库文档、测试和 Git 为准

状态：Accepted  
适用范围：软件仓库和插件仓库

## 决策

不依赖聊天记录保存项目状态。每个仓库提供一个短 `AI.md`，当前任务写入 `docs/maintainer/tasks/active.md`，稳定架构决策写入 ADR，行为约束由测试和类型定义固定。

## 读取规则

新对话只读取工作区路由、目标仓库 `AI.md`、当前任务，再按需读取模块文档、ADR、源码和测试。历史归档默认不读。

## 规模规则

- `AI.md` 只做地图和规则，不超过约两页。
- 当前任务只保留当前状态，不无限追加历史。
- 完成任务移入归档。
- 不复制聊天记录、完整源码和完整日志。

## 结果

上下文采用即时读取，避免随着项目和对话增长而整体膨胀；代码行为以测试和实际实现为最终依据，文档发现冲突时必须更新文档或测试。
